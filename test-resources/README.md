# 视频生成接口测试资源

## 需要你放入的文件

### images/ — 图片素材

| 文件 | 用途 | 要求 |
|------|------|------|
| `first-frame.png` | 首帧图 | 任意场景图，用于图生视频的起始帧 |
| `last-frame.png` | 尾帧图 | 与首帧不同场景，用于首尾帧过渡测试 |
| `reference-1.png` | 参考图1 | 任意图，测试单张参考效果 |
| `reference-2.png` | 参考图2 | 任意图，测试多参考图 |
| `reference-3.png` | 参考图3 | 任意图，测试多参考图(3张上限) |
| `face-photo.jpg` | 真人照片 | **正面人脸**，测试Asset审核链路 |

### videos/ — 视频素材

| 文件 | 用途 | 要求 |
|------|------|------|
| `reference-video.mp4` | 参考视频 | 2-15秒mp4，测试参考视频功能 |

### prompts/ — 提示词

| 文件 | 用途 |
|------|------|
| `text-only.txt` | 纯文生视频提示词 |
| `with-images.txt` | 带图生视频提示词（用"图片1""图片2"引用参考图） |
| `with-face.txt` | 带真人参考的提示词 |
| `with-video.txt` | 带视频参考的提示词 |
